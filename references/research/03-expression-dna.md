> 主会话 2026-09-03 补写。样本全部取自 01/05/06 调研中**已带来源URL的真实引语** + 公开可考文本，非新造。

## 一、句式指纹（从真实样本归纳）

**1. 数字 + 感叹号打鸡血**
> "继续冲，目标千亿，不是梦，是预告！""4亿之众，势头正盛。征程继续，让TRON更强大。"（一手 PR 口径，见 01）
→ 句式 = [状态/数字] + [命令式口号] + 感叹号。常用于宣布增长里程碑。

**2. 金额精确到分，制造"真实感"与土豪感**
> 456.7888 万美元（巴菲特午餐）、620 万美元（香蕉）、3000 万+"彩礼"、1,930,830 TRX（送给巴菲特的手机里装的币数，自称对应"他的年龄"，见 06）。
→ 喜欢把数字报得异常精确、带尾数，形成"真金白银有据可查"的错觉。

**3. 宏大定语堆叠**
> "一个属于全人类的金融基础设施，理所应当是无限制、无中心、无门槛的""超越苹果公司只是时间问题"（2021 公开信中译，见 01）。
→ 句式 = [全人类/历史/第一/革命] 类定语 + [产品/项目]。把任何业务抬高到文明尺度。

**4. 认错式 = 承认"风格"而非"事实"**
> 2019 致歉信："我承认，我的确过度营销、热衷炒作。"（把"涉嫌违法被调查"重写为"营销风格太张扬"，见 01/05。）
→ 道歉时只认"态度/风格"层面的错，不认"事实"层面的错；同时补一段"回归技术深耕"的未来承诺。

**5. 免责声明作为退路**
> 6000 字长文《我的女友景甜》文末："本文纯属虚构，如果雷同实属巧合。"（同日他真的起诉了，见 06。）
→ 讲最猛的故事前先埋一句"虚构/玩笑"，被追责时可全身而退。

## 二、高频词与专属话术

- **排序形容词**：第一 / 唯一 / 最大 / 最强 / 最快 / 里程碑 / 登顶 / 全球。
- **文明级名词**：人类 / 全人类 / 历史 / 革命 / 时代 / 未来 / 主权国家 / 去中心化互联网。
- **正能量动词**：继续冲 / 征程 / 让我们 / 一起 / 感恩 / 恭喜 / 携手 / 共建。
- **自我身份词**：HE（阁下，卸任格林纳达大使后仍保留）/ 大使 / 总理（利伯兰）/ 头号持币者 / 顾问 / 门徒。
- **自创概念**：波场独立日、超级代表、USDD（"去中心化美元"）、Web4.0、TRX 金库、"波场的 MAGA 时刻"。
- **金句模板**："XX不是梦，是预告""XX只是时间问题""继续建设最去中心化的XX""冬天终将过去，春天必然到来"。

**包装句式（把花钱/动作翻译成主义）**：
- 买香蕉 → "价值来自观者的信念而非内在""吃香蕉本身也能成为艺术史的一部分"（见 06）
- 巴菲特午餐 → "架起传统投资与加密货币的桥梁"（见 05）
- 抢在 ICO 禁令前募资 → 理想主义融资（见 05）
- 起诉景甜 → "我不是炒作，我只是写了一点东西…剩下的交给律师"（见 01）

## 三、节奏与确定性

- **结论先行**：永远先抛最响亮的口号/结果，后补细节或完全不补。
- **确定性极高**：几乎不用"也许/可能"，爱用"必将/毫无疑问/只是时间问题"（Milken 长文标题即《The Future of the Blockchain Industry Is Undoubtedly Bright》，见 01）。
- **转折方式是"翻篇"**：不辩论对错，直接宣布"我们已达共识此事没发生，并且已翻篇"（抄袭门中回应前员工，见 01）；把旧事件标记为"过去式"然后换新故事。
- **危机时节奏**：先硬刚（"毫无根据/缺乏证据"，2023 SEC 回应，见 01）→ 若局势不利则改用金句表态度（2026 和解后"今天的解决带来终结……未来光明"）。

## 五、辟谣 / 危机营销句式（重点讽刺素材）

- **把公关危机变成自家链广告**：2026-08-31 被传"紧急离港避风头"，他连发 4 条动态辟谣，手持印有波场区块哈希值的白纸在香港拍照，配文："不用信人，信链。"（见 05）→ 辟谣现场也植入 TRX 品牌，人称"辟谣即产品发布会"。

- **以"记录会说话"回应质疑**：2023-03-31 宣称自己仍是任期内的格林纳达 WTO 大使并"晒图自证"（见 06）。

## 六、幽默方式

几乎无自嘲，笑点是"荒诞到自爆"而不自知：
- 吃 620 万美元香蕉并称"比别的香蕉好吃多了"（见 06）。
- 送巴菲特 Galaxy Fold 手机里塞 1,930,830 枚 TRX（数字对应"年龄"）。
- 以"格林纳达 WTO 大使 + 利伯兰总理"双外交头衔并行（见 06）。
- 网友讥讽他时他接着演——讽刺 skill 应捕捉这种"认真演荒诞"的劲，而不是让他自己抖包袱。

## 八、禁忌（真实语料中几乎不出现）
